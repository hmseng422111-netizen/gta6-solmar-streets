Solmar Streets — a complete top-down open-world crime game in the spirit of GTA 6: drive and walk around the sun-soaked coastal city of Solmar, steal cars, outrun the Solmar PD across five wanted levels, and pull off three story jobs plus taxi fares. Pure HTML5 Canvas and JavaScript, no libraries, no network.

## Run it

```sh
node serve.ts — then open http://localhost:8080
```
